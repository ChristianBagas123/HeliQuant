**Agent token 11** (`carry.heliquant.testnet`). The Carry desk watches **delta-neutral funding-carry** — the yield from holding
spot and shorting the perp to harvest funding — a **market-neutral** opportunity, explicitly **not** a
directional signal.

## What it reads

`firm/organization.py · tool_carry()` (over `firm/carry_signal.py`):

- **This asset's carry** — trailing perp funding annualized vs the risk-free rate.
- **Best harvestable** — scans the perp universe and returns the most attractive carry with its
  `crash_class` (crash-stress robustness) and verdict.

## Why it's only advisory

Funding-carry is a **yield** play, not alpha on price. It earns when funding is rich and the position is
held delta-neutral, and it is single-venue executable. The rate is computed live from Bitget funding;
`crash_class` comes from a fixed stress-test table in `firm/carry_signal.py` (re-run with `scripts/77`). Carry
is not a validated edge in the registry. The verdict is **HARVEST** only when the annualized carry beats the
risk-free rate **and** the asset's `crash_class` is `robust`; carry below risk-free, or an asset that is `lumpy`,
`tame` or untested, is a **skip**. Either way the desk stays out of the directional vote.

## Output (shape — illustrative values)

```json
{
  "asset": "HYPE",
  "this_asset_carry": { "symbol": "HYPEUSDT", "carry_ann_pct": 0.0, "crash_class": "robust", "attractive": false },
  "best_harvestable": null,
  "read": "no harvestable carry above risk-free right now",
  "caveat": "market-neutral yield option, NOT a directional signal"
}
```

## Honest caveats

Carry is **non-directional** — it never says "buy" or "sell" the asset; it flags a market-neutral yield
when one exists. It is a monitor, not an executor: it never opens a carry position itself.
