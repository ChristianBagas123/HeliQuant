**Agent token 12** (`near-fundamentals.heliquant.testnet`). Reads **NEAR chain fundamentals** from DeFiLlama
(free, keyless) and turns them into an **ecosystem risk-on / risk-off** tilt — chain-level context, not an
asset-specific trade signal.

## What it reads

`firm/organization.py · tool_defillama()` (over `firm/defillama_client.py`):

- **Chain TVL** — NEAR total-value-locked + 7d / 30d change + trend (rising / falling / stable).
- **Fees** — 24h chain fees.
- **Staking yields** — top NEAR staking-yield pools.

It maps the TVL trend to `ecosystem_risk`: rising TVL → **risk-ON (capital inflow)**, falling →
**risk-OFF (outflow)**, flat → stable.

## Output (shape — live values fetched each cycle)

```json
{
  "asset": "NEAR",
  "near_tvl_usd": 0, "tvl_chg7d_pct": 0.0, "tvl_chg30d_pct": 0.0, "tvl_trend": "stable",
  "fees_24h_usd": 0, "top_staking_yields": [],
  "ecosystem_risk": "stable",
  "caveat": "advisory ecosystem context (chain-level), not an asset-specific trade signal"
}
```

## Honest caveats

This is **advisory context**, not an edge: chain TVL / fees describe ecosystem health, not where NEAR goes
next. It tilts risk appetite — a weak SHORT lean when TVL is falling, as the campaign's `_near_lean` reads it
for NEAR-ecosystem assets — and that lean is **unvalidated**. A snapshot on 2026-11-09 showed NEAR TVL of
about $165M, down 15.5% over 7 days and 28.2% over 30 days.
